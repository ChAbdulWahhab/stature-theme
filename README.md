## Stature

A dark VS Code theme built for long sessions. No neon. No decoration for its own sake. The interface recedes so your code can breathe.

Stature is built on a monochromatic dark green-grey palette — the color of old forests and quiet terminals. Every color was chosen with one question: does this earn its place?

## Variants

Six variants. One palette. Pick your depth.

| Variant | Character |
|---|---|
| **Stature** | The original. Dark green-grey. Zero compromise. |
| **Stature Void** | Pitch black for OLED screens. The editor disappears. |
| **Stature Dusk** | One shade lighter. Same soul. |
| **Stature Warm** | Amber replaces green. Old leather. Different temperature, same focus. |
| **Stature High Contrast** | Brighter foregrounds. Sharper syntax. Same dark base. |
| **Stature Italic** | Italic accents on comments, flow, and decorators. For those who read code as prose. |

## Color System

The entire theme is built on three scales.
Nothing exists outside them.

**Backgrounds**
```
#161916  #1A1D1A  #1E1E1E  #232823
```

**Accents**
```
#2D3F35  #4C6B5A  #7A9E8A
```

**Text**
```
#3D4D45  #7A8A7A  #CDD6CD
```

One warm deviation: `#C4A882` for numbers and literals. That is the only color that breaks from the green-grey family — and it does so deliberately.

## Syntax Philosophy

Comments are dim. They recede.
Keywords are green. They structure.
Strings are lighter. They carry content.
Numbers are amber. They stand apart.
Functions are near-white. They are the work.
Punctuation is near-invisible. It is the scaffolding.

No token shouts. Differentiation comes from hue and weight — not saturation.

## Installation

**From Marketplace:**
Search `Stature` in VS Code Extensions → Install

**From VSIX:**
```bash
code --install-extension stature-0.0.2.vsix
```

**Activate:**
```
Ctrl+K  Ctrl+T  →  Stature
```
